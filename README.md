# TecnoFácil S.R.L. — Sistema Integrado de Gestión

## Descripción del sistema

El presente proyecto propone el desarrollo de un sistema integrado de gestión para TecnoFácil S.R.L., orientado a mejorar el control de ventas, productos, stock, usuarios y reportes.

El sistema permitirá registrar ventas, validar la disponibilidad de productos, descontar automáticamente el stock, generar comprobantes y brindar información para la toma de decisiones.

## Objetivo general

Mejorar la organización, el control y la trazabilidad de las operaciones comerciales y de depósito de TecnoFácil S.R.L. mediante un sistema de información integrado.

## Alcance

- Gestión de productos.
- Control de stock.
- Registro de ventas.
- Gestión de usuarios y roles.
- Generación de reportes.
- Alertas por faltantes o stock mínimo.
